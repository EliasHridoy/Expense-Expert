1. Create `src/features/dashboard/components/SummaryCard.tsx`:
   - Props interface `SummaryCardProps`:
     - `title: string`
     - `amountFormatted: string`
     - `icon?: string`
     - `type?: 'income' | 'expense' | 'savings' | 'neutral'`
     - `isNegative?: boolean`
     - `subtext?: string`
     - `badgeText?: string`
     - `badgeColor?: string`
     - `onPress?: () => void`
     - `testID?: string`
   - Render styling:
     - Card container: `bg-white dark:bg-slate-800 rounded-2xl p-4 sm:p-5 border border-slate-100 dark:border-slate-700 shadow-xs`.
     - Icon container: rounded badge with pastel background matched to metric type.
     - Title: `text-xs uppercase tracking-wider font-semibold text-slate-500 dark:text-slate-400`.
     - Amount: `text-xl sm:text-2xl font-black` with color:
       - If `isNegative`: red/rose (`text-rose-600 dark:text-rose-400`).
       - If `type === 'income'`: emerald/green (`text-emerald-600 dark:text-emerald-400`).
       - If `type === 'expense'`: rose/red (`text-rose-600 dark:text-rose-400`).
       - If `type === 'savings'`: indigo (`text-indigo-600 dark:text-indigo-400`).
       - Else: neutral slate (`text-slate-900 dark:text-white`).
     - Subtext: `text-xs text-slate-400 dark:text-slate-500 mt-1`.
     - If `onPress` provided, wrap with `TouchableOpacity` with accessibility role `button`.

2. Create `src/features/dashboard/components/SummaryCardsGrid.tsx`:
   - Props: `summary: MonthSummary`, `onPressCard?: (cardKey: string) => void`.
   - Responsive multi-column layout (`w-full flex-row flex-wrap -mx-2` with `w-full sm:w-1/2 lg:w-1/4 p-2`).
   - Renders:
     1. **Total Income:** `formatCents(summary.totalIncomeInCents)`, subtext showing past carryover breakdown if `summary.previousMonthRemainingInCents !== 0`, type: `income`, icon: `💰`.
     2. **Total Expenses:** `formatCents(summary.totalExpensesInCents)`, subtext `${summary.expenseCount} transaction(s)`, type: `expense`, icon: `💳`.
     3. **Total Savings:** `formatCents(summary.totalSavingsInCents)`, subtext "Net deposits this month", type: `savings`, icon: `🏦`.
     4. **Net Remaining:** `formatCents(Math.abs(summary.remainingInCents))`, `isNegative={summary.remainingInCents < 0}`, type: `income`/`expense` based on sign, icon: `✨`/`⚠️`, subtext "Surplus balance" / "Deficit this month".
     5. **Loans Taken (Conditional or 5th card):** If `summary.loansTakenIncomeInCents > 0`, display borrowed cash card with `formatCents(summary.loansTakenIncomeInCents)`, subtext "Inflow from loans", type: `neutral`, icon: `🤝`.

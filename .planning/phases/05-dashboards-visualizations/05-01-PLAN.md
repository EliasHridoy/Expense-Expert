Inside `expense-expert-rn/`:

1. Create `src/features/dashboard/utils/aggregation.util.ts`:
   - Import `toCents`, `fromCents`, `addCents`, `subtractCents` from `../../expenses/utils/currency.util`.
   - `resolveSalaryInCents(profile, targetMonth: string): number`:
     - If profile has `salaries[targetMonth]`, return `toCents(profile.salaries[targetMonth])`.
     - Else if profile has `salaries` map, sort keys and find the closest preceding month (or earliest available).
     - Fallback to `toCents(profile.monthlySalary ?? 0)`.
   - `getMonthsBetween(startDate: Date, endMonthStr: string): string[]`:
     - Generates array of `YYYY-MM` strings from `startDate` up to, but excluding, `endMonthStr`.
   - `computeMonthSummary(data: RawFinancialData): MonthSummary`:
     - Filters records matching `data.month`.
     - Computes current month `totalExpensesInCents`, `totalSavingsInCents` (deposits add, withdrawals subtract), `savingsInExpensesInCents` (expenses with `category.toLowerCase() === 'savings'`).
     - Computes `currentMonthIncomeInCents = salaryInCents + additionalIncomeInCents + loansTakenIncomeInCents`.
     - Rolls forward previous months from `profile.createdAt` to compute `previousMonthRemainingInCents` using the exact formula:
       `pNetRemaining = pTotalIncome - pTotalExpenses - (pTotalSavings - pSavingsInExpenses)`.
     - Computes `totalIncomeInCents = currentMonthIncomeInCents + previousMonthRemainingInCents`.
     - Computes `remainingInCents = totalIncomeInCents - totalExpensesInCents - (totalSavingsInCents - savingsInExpensesInCents)`.
     - Returns populated `MonthSummary` with both cents and float formats.
   - `computeCategoryBreakdown(expenses: RawFinancialData['expenses'], month: string): CategoryBreakdown[]`:
     - Groups month expenses by category, aggregating `totalInCents` and `count`.
     - Calculates `percentage` (1 decimal place: `(total / grandTotal) * 100`).
     - Sorts descending by `totalInCents`.
   - `computeMonthlyTrend(expenses: RawFinancialData['expenses'], savingEntries: RawFinancialData['savingEntries'], months: string[]): MonthlyTrend[]`:
     - Maps each month key to `{ month, totalExpensesInCents, totalExpenses, totalSavingsInCents, totalSavings }`.
   - `getPastMonthKeys(count: number = 6, referenceDate: Date = new Date()): string[]`:
     - Returns array of `YYYY-MM` strings for past `count` months in chronological order.

1. Create `src/features/dashboard/services/dashboard.service.ts`:
   - Cache keys:
     - `DASHBOARD_SUMMARY_CACHE_PREFIX = '@expense_expert_dashboard_summary_'`
     - `DASHBOARD_TREND_CACHE_PREFIX = '@expense_expert_dashboard_trend_'`
     - `DASHBOARD_BREAKDOWN_CACHE_PREFIX = '@expense_expert_dashboard_breakdown_'`
   - `fetchRawFinancialData(userId: string, targetMonth: string): Promise<RawFinancialData>`:
     - Queries `users/{userId}/expenses` with `where('month', '<=', targetMonth)`.
     - Queries `users/{userId}/saving-entries` with `where('month', '<=', targetMonth)`.
     - Queries `users/{userId}/income-entries` with `where('month', '<=', targetMonth)`.
     - Queries `users/{userId}/loans-taken` with `where('month', '<=', targetMonth)`.
     - Fetches user profile document `users/{userId}` to extract `monthlySalary`, `salaries`, and `createdAt`.
     - Returns `RawFinancialData` object.
   - `getMonthSummary(userId: string, month: string): Promise<MonthSummary>`:
     - Fetches raw data from Firestore, computes summary via `computeMonthSummary(raw)`.
     - Caches result in `AsyncStorage` under `${DASHBOARD_SUMMARY_CACHE_PREFIX}${userId}_${month}`.
     - On network/Firestore error, falls back to `AsyncStorage` cached summary if present.
   - `getMonthlyTrend(userId: string, monthsCount: number = 6, referenceMonth?: string): Promise<MonthlyTrend[]>`:
     - Computes list of month keys via `getPastMonthKeys`.
     - Fetches raw financial data up to the latest month.
     - Computes trends via `computeMonthlyTrend`.
     - Caches in `AsyncStorage` and falls back to cache on error.
   - `getCategoryBreakdown(userId: string, month: string): Promise<CategoryBreakdown[]>`:
     - Fetches expenses for target month.
     - Computes category breakdowns via `computeCategoryBreakdown`.
     - Caches in `AsyncStorage` and falls back to cache on error.

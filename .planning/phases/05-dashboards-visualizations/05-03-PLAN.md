2. Create `src/features/dashboard/utils/svg-chart.util.ts`:
   - `export interface SvgPieSlice`:
     ```typescript
     export interface SvgPieSlice {
       id: string;
       label: string;
       valueInCents: number;
       percentage: number;
       color: string;
       pathData: string;
       startAngle: number;
       endAngle: number;
       midAngle: number;
     }
     ```
   - `polarToCartesian(centerX: number, centerY: number, radius: number, angleInDegrees: number)`:
     - Converts polar coordinates to cartesian `{ x, y }` with angle offset `-90°` so `0°` starts at 12 o'clock.
   - `createDonutSlicePath(centerX, centerY, outerRadius, innerRadius, startAngle, endAngle)`:
     - Clamps `safeEndAngle = endAngle - startAngle >= 360 ? startAngle + 359.999 : endAngle` to prevent SVG 0-length arc collapse.
     - Builds SVG `M ... A ... L ... A ... Z` path string with `largeArcFlag`.
   - `generateDonutSlices(items: Array<{ id: string; label: string; valueInCents: number; color: string }>, size: number = 200, strokeWidth: number = 32): SvgPieSlice[]`:
     - Computes cumulative angles and percentages for each item.
     - Returns array of `SvgPieSlice`.
   - `normalizeBarScale(values: number[], targetHeight: number): { maxVal: number; scaleFactor: number; gridTicks: number[] }`:
     - Computes round upper bound `maxVal` and step grid ticks for Y-axis scale.
   - `CATEGORY_PALETTE`:
     - Array of 10 distinct, accessible hex colors: `['#6366f1', '#ec4899', '#f59e0b', '#10b981', '#8b5cf6', '#06b6d4', '#f43f5e', '#14b8a6', '#f97316', '#64748b']`.

   - Test `generateDonutSlices`:
     - Returns empty array on zero or empty inputs.
     - Handles 100% single slice without 0-length arc collapse (clamps to 359.999°).
     - Computes correct percentage share (rounded to 1 decimal).
   - Test `normalizeBarScale` produces nice step values and nonzero scale factors.

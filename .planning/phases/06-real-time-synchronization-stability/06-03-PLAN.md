# Plan 06-03: Universal Error Boundary, Toast System & Connection Banner

## Overview
Implement application resilience components: a universal React `ErrorBoundary` with graceful recovery fallback, a zero-dependency `ToastProvider` for notifications across React Native Web and Mobile, and a `ConnectionStatusBanner` displaying live offline/sync state. Integrate these directly into `app/_layout.tsx` and `app/(app)/_layout.tsx`.

          testID="error-boundary-fallback"

# Plan 06-02: Real-time Listener Integration & Optimistic Offline Reconciliation

## Overview
Connect Firestore `onSnapshot` real-time listeners across all domain providers (`ExpenseProvider`, `CategoryProvider`, `BudgetProvider`, and `DashboardProvider`). Integrate intelligent optimistic offline reconciliation into `ExpenseProvider` to ensure pending offline mutations are preserved seamlessly when server snapshots arrive, fulfilling SYNC-01 and SYNC-02.

    - Query `users/${userId}/expenses` with `where('month', '==', month)` and `orderBy('date', 'desc')`.

      ```typescript
      setExpenses((prev) => {
        const pendingItems = prev.filter((item) => item.syncStatus === 'pending');
        const remoteIds = new Set(remoteExpenses.map((e) => e.id));
        const uniquePending = pendingItems.filter((e) => !remoteIds.has(e.id));
        return [...uniquePending, ...remoteExpenses];
      });
      ```

     - Access `{ user, isLoading }` via `useAuth()`.
     - Access `segments = useSegments()` and `router = useRouter()`.
     - In `useEffect`:
       - If `isLoading` is true, do not navigate.
       - Check `const inAuthGroup = segments[0] === '(auth)'`.
       - If `!user && !inAuthGroup`, `router.replace('/(auth)/login')`.
       - If `user && inAuthGroup`, `router.replace('/(app)')`.
     - If `isLoading` is true, render a full-screen loading spinner (`View` with `ActivityIndicator` centered) to prevent flashing unauthenticated routes.
     - When `isLoading` is false, render `<Slot />`.

2. Update `app/index.tsx`:
   - Root redirector:
     ```typescript
     import { Redirect } from 'expo-router';
     import { useAuth } from '../src/features/auth/hooks/useAuth';

     export default function RootIndex() {
       const { user, isLoading } = useAuth();
       if (isLoading) return null;
       return user ? <Redirect href="/(app)" /> : <Redirect href="/(auth)/login" />;
     }
     ```

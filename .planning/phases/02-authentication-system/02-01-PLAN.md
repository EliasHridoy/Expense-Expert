2. Create `src/features/auth/utils/auth-errors.ts` translating Firebase error codes to user-friendly messages:
   ```typescript
   export function getAuthErrorMessage(code: string): string {
     switch (code) {
       case 'auth/user-not-found':
       case 'auth/wrong-password':
       case 'auth/invalid-credential':
         return 'Invalid email or password';
       case 'auth/email-already-in-use':
         return 'An account with this email already exists';
       case 'auth/weak-password':
         return 'Password must be at least 6 characters';
       case 'auth/invalid-email':
         return 'Invalid email address';
       case 'auth/too-many-requests':
         return 'Too many attempts. Please try again later.';
       case 'auth/user-disabled':
         return 'This account has been disabled';
       case 'auth/network-request-failed':
         return 'Network error. Please check your internet connection.';
       case 'auth/popup-closed-by-user':
         return 'Sign-in cancelled';
       default:
         return 'Authentication failed. Please try again.';
     }
   }
   ```

3. Create `__tests__/features/auth/auth-errors.test.ts` covering error translation for all standard codes and the fallback.

1. Create `src/features/auth/services/auth.service.ts`:
   - Import modular Firebase Auth methods (`signInWithEmailAndPassword`, `createUserWithEmailAndPassword`, `updateProfile`, `signOut`, `signInWithPopup`, `GoogleAuthProvider`, `User`).
   - Import Firestore methods (`doc`, `getDoc`, `setDoc`, `serverTimestamp`).
   - Import `auth` and `db` from `src/config/firebase`.
   - Implement `AuthService`:
     - `login({ email, password })`: trims email, authenticates with `signInWithEmailAndPassword`, calls `ensureUserDocument(user)`, and returns `user`.
     - `register({ email, password, displayName })`: trims email, calls `createUserWithEmailAndPassword`, updates profile with `displayName` if provided, calls `ensureUserDocument(user, displayName)`, and returns `user`.
     - `signInWithGoogle()`: on web, creates `GoogleAuthProvider` and calls `signInWithPopup`, ensures user document, and returns `user`. If called on non-web platforms, throws an informative error.
     - `logout()`: calls `signOut(auth)`.
     - `ensureUserDocument(user, customDisplayName?)`: checks `users/{uid}` in Firestore. If document does not exist, creates document with `{ uid: user.uid, email: user.email || '', displayName: customDisplayName || user.displayName || user.email?.split('@')[0] || 'User', createdAt: serverTimestamp(), updatedAt: serverTimestamp() }`. If it exists, returns the existing profile data merged with `uid` and `email`.

   - Mock `firebase/auth` and `firebase/firestore`.
   - Test successful `login` calling `signInWithEmailAndPassword` and syncing Firestore document.
   - Test successful `register` calling `createUserWithEmailAndPassword`, `updateProfile`, and Firestore `setDoc`.
   - Test `ensureUserDocument` creating new document when none exists, or returning existing data when doc exists.
   - Test `logout` calling `signOut`.
   - Test `signInWithGoogle` behavior on web vs non-web platforms.

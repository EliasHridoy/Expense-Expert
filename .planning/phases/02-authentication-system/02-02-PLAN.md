   - Consume `useAuth()` to get `login` and `signInWithGoogle`.
   - Email and Password text inputs with labels, placeholders (`you@example.com`, `••••••••`), and `secureTextEntry` for password.
   - Submit button with `Sign in` / `ActivityIndicator` loading state. Button disabled if `!email || !password || isSubmitting`.
   - Catch errors and display human-friendly text using `getAuthErrorMessage(error.code)`.
   - Include Google `SocialAuthButton` divider ("Or continue with").

2. Create `src/features/auth/components/RegisterForm.tsx`:
   - State for `displayName`, `email`, `password`, `confirmPassword`, `isSubmitting`, `errorMessage`.
   - Client validation helper:
     - `isFormValid = displayName.trim() && email.trim() && password && confirmPassword && password === confirmPassword && password.length >= 6`.
   - Show inline validation message when `password && confirmPassword && password !== confirmPassword` ("Passwords do not match").
   - Show inline validation note when `password && password.length < 6` ("Password must be at least 6 characters").
   - Submit button with `Create account` / `ActivityIndicator` loading state. Button disabled if `!isFormValid || isSubmitting`.
   - Consume `register` from `useAuth()`. On submit, call `register({ email, password, displayName })`.
   - Catch errors and display message using `getAuthErrorMessage(error.code)`.
   - Include Google `SocialAuthButton` option.
   - Include Link to login screen: `Already have an account? Sign in` (navigates to `/(auth)/login`).

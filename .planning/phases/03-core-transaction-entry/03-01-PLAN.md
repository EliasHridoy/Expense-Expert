Inside `expense-expert-rn/`:

1. Create `src/features/expenses/utils/currency.util.ts`:
   - `toCents(amount: number | string | null | undefined): number`:
     - If null/undefined/empty string, returns 0.
     - If number: handles `Math.round(amount * 100)`. Filters NaN or infinite numbers to 0.
     - If string: strips non-numeric characters except `-` and `.`. Splits whole and fractional components, padding fractional to 2 places (`padEnd(2, '0').slice(0, 2)`), computing `whole * 100 + fraction`. Handles negative signs accurately.
     - Guarantees `1.15` converts to `115`, `"19.99"` converts to `1999`, `"$1,250.50"` converts to `125050`.
   - `fromCents(cents: number): number`:
     - Converts integer cents back to decimal float (`Math.round(cents) / 100`).
     - Returns 0 if NaN or null.
   - `addCents(a: number, b: number): number`:
     - Returns `Math.round(a) + Math.round(b)`.
   - `subtractCents(a: number, b: number): number`:
     - Returns `Math.round(a) - Math.round(b)`.
   - `multiplyCents(cents: number, factor: number): number`:
     - Returns `Math.round(cents * factor)`.
   - `divideCents(cents: number, divisor: number): number`:
     - Throws Error if `divisor === 0`.
     - Returns `Math.round(cents / divisor)`.
   - `formatCents(cents: number, currency: string = 'USD', locale: string = 'en-US'): string`:
     - Formats integer cents via `Intl.NumberFormat(locale, { style: 'currency', currency, minimumFractionDigits: 2, maximumFractionDigits: 2 })`.

2. Create `__tests__/features/expenses/currency.util.test.ts`:
   - Test `toCents`:
     - Parses integers (`10` -> `1000`), decimals (`10.5` -> `1050`, `19.99` -> `1999`, `1.15` -> `115`).
     - Parses formatted strings (`"12.34"` -> `1234`, `"$1,250.00"` -> `125000`, `".5"` -> `50`, `"0.05"` -> `5`, `"-5.50"` -> `-550`).
     - Handles invalid and edge cases (`null`, `undefined`, `""`, `"-"`, `"abc"`, `NaN`, `Infinity` all return `0`).
     - Proves elimination of float drift (`0.1 + 0.2` cents addition equals `30` cents, not `30.000000000000004`).
   - Test `fromCents`:
     - Converts `1999` -> `19.99`, `0` -> `0`, `-550` -> `-5.5`.
   - Test `addCents`, `subtractCents`, `multiplyCents`, `divideCents`:
     - Add: `100 + 200 = 300`
     - Subtract: `300 - 100 = 200`
     - Multiply: `100 * 1.5 = 150`
     - Divide: `100 / 3 = 33`, throws on divisor 0
   - Test `formatCents`:
     - `1999` -> `"$19.99"`
     - `0` -> `"$0.00"`
     - `-500` -> `"-$5.00"` (or localized USD equivalent)

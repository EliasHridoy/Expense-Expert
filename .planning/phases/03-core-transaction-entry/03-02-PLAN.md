Inside `expense-expert-rn/`:

1. Create `src/features/expenses/hooks/useNetworkStatus.ts`:
   - Hook returning `{ isOnline: boolean }`.
   - On web (`Platform.OS === 'web' && typeof window !== 'undefined'`):
     - Sets initial state to `navigator.onLine`.
     - Subscribes to `window.addEventListener('online')` and `window.addEventListener('offline')`.
   - On native:
     - Subscribes to `NetInfo.addEventListener((state) => { setIsOnline((state.isConnected ?? true) && (state.isInternetReachable ?? true)); })`.
   - Cleans up event listeners on unmount.

2. Create `src/features/expenses/services/expense.service.ts`:
   - Import modular Firestore functions (`collection`, `doc`, `getDoc`, `getDocs`, `setDoc`, `updateDoc`, `deleteDoc`, `query`, `where`, `orderBy`, `serverTimestamp`).
   - Import `db` from `src/config/firebase`.
   - Import `toCents`, `fromCents` from `../utils/currency.util`.
   - Import `formatMonth`, `toISODate` from `../utils/date.util`.
   - Import `OfflineQueueService` from `./offline-queue.service`.
   - Methods:
     - `getExpensesPath(userId: string): string`: `users/${userId}/expenses`.
     - `generateExpenseId(): string`: Generates client UUID `exp_${Date.now()}_${Math.random().toString(36).substr(2, 9)}`.
     - `addExpense(userId: string, dto: CreateExpenseDto, isOnline: boolean): Promise<Expense>`:
       - Computes `amountInCents = toCents(dto.amount)`, `amount = fromCents(amountInCents)`.
       - Computes `month = formatMonth(dto.date)`.
       - Creates full `Expense` object with `syncStatus: isOnline ? 'synced' : 'pending'`.
       - If `isOnline`: attempts `setDoc(doc(db, path, expenseId), { ...expense, createdAt: serverTimestamp(), updatedAt: serverTimestamp() })`.
       - If offline or if `setDoc` throws network error: enqueues `CREATE_EXPENSE` in `OfflineQueueService` and returns optimistic `Expense` with `syncStatus: 'pending'`.
     - `updateExpense(userId: string, id: string, dto: UpdateExpenseDto, isOnline: boolean): Promise<void>`:
       - Prepares payload (updates `amountInCents`, `month` if date changed).
       - If `isOnline`: calls `updateDoc(doc(db, path, id), { ...payload, updatedAt: serverTimestamp() })`.
       - If offline or error: enqueues `UPDATE_EXPENSE` in `OfflineQueueService`.
     - `deleteExpense(userId: string, id: string, isOnline: boolean): Promise<void>`:
       - If `isOnline`: calls `deleteDoc(doc(db, path, id))`.
       - If offline or error: enqueues `DELETE_EXPENSE` in `OfflineQueueService`.
     - `getExpensesByMonth(userId: string, month: string): Promise<Expense[]>`:
       - Queries Firestore `where('month', '==', month)`, `orderBy('date', 'desc')`.
     - `getExpenseById(userId: string, id: string): Promise<Expense | null>`:
       - Fetches single expense doc.
     - `processSyncQueue(userId: string): Promise<number>`:
       - Retrieves pending mutations for `userId` from `OfflineQueueService`.
       - Executes each in FIFO sequence (creates, updates, deletes) with idempotent `setDoc`/`updateDoc`/`deleteDoc`.
       - On success, removes mutation from queue.
       - On error, marks failed and aborts if network connection is dropped.
       - Returns count of successfully synced mutations.

3. Create `__tests__/features/expenses/expense.service.test.ts`:
   - Mock Firebase Firestore and `OfflineQueueService`.
   - Test `addExpense` when online calls `setDoc` with server timestamps and returns `syncStatus: 'synced'`.
   - Test `addExpense` when offline enqueues mutation and returns `syncStatus: 'pending'`.
   - Test `addExpense` falls back to offline queue if Firestore `setDoc` rejects.
   - Test `processSyncQueue` flushes queued mutations in order, writing to Firestore and removing from queue.
  </action>

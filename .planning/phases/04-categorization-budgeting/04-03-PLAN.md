2. Create `src/features/budgets/utils/budget.util.ts`:
   - `calculateBudgetUsage(budget: CategoryBudget, matchingExpenses: Expense[]): BudgetUsage`:
     - Resolves `limitInCents` (from `budget.limitInCents` or `toCents(budget.limit)`).
     - Sums `amountInCents` for expenses where `e.category === budget.category && e.month === budget.month`.
     - Computes `remainingInCents = subtractCents(limitInCents, spentInCents)`.
     - Computes percentage: `limitInCents > 0 ? (spentInCents / limitInCents) * 100 : 0`.
     - Evaluates threshold using integer arithmetic:
       - `exceeded`: `spentInCents >= limitInCents` (or `percentage >= 100`)
       - `warning`: `spentInCents * 100 >= limitInCents * 80` (or `percentage >= 80`)
       - `under`: otherwise (< 80%)
     - Returns full `BudgetUsage` object with rounded percentage (1 decimal place).
   - `calculateTotalBudgetSummary(budgets: CategoryBudget[], expenses: Expense[], month: string): BudgetSummary`:
     - Sums total limits across all budgets in `month`.
     - Sums total spent across all expenses in `month` for budgeted categories (or all expenses in month).
     - Computes remaining balance, total percentage, and threshold state.
   - `getThresholdColor(state: ThresholdState)`:
     - Returns styling classes:
       - `under`: `{ barColor: 'bg-emerald-500', textColor: 'text-emerald-600 dark:text-emerald-400', badgeBg: 'bg-emerald-100 dark:bg-emerald-950/60', badgeText: 'text-emerald-700 dark:text-emerald-300' }`
       - `warning`: `{ barColor: 'bg-amber-500', textColor: 'text-amber-600 dark:text-amber-400', badgeBg: 'bg-amber-100 dark:bg-amber-950/60', badgeText: 'text-amber-700 dark:text-amber-300' }`
       - `exceeded`: `{ barColor: 'bg-rose-500', textColor: 'text-rose-600 dark:text-rose-400', badgeBg: 'bg-rose-100 dark:bg-rose-950/60', badgeText: 'text-rose-700 dark:text-rose-300' }`

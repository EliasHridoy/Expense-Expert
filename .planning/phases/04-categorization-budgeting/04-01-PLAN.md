Inside `expense-expert-rn/`:

1. Create `src/features/categories/services/category.service.ts`:
   - Cache key constant: `const CATEGORIES_CACHE_KEY = '@expense_expert_categories_cache';`
   - `getCategoriesPath(userId: string): string` -> returns `users/${userId}/categories`.
   - `getBuiltInCategories(): CategoryItem[]` -> returns formatted list of built-in categories from `EXPENSE_CATEGORIES`.
   - `fetchCustomCategories(userId: string): Promise<CategoryItem[]>`:
     - Queries Firestore collection `users/${userId}/categories` ordered by `name asc`.
     - Maps docs to `CategoryItem` format (`id: doc.id`, `value: doc.id`, `label: data.name`, `icon: data.icon || '📁'`, `isCustom: true`).
     - Persists fetched items to `AsyncStorage` under `${CATEGORIES_CACHE_KEY}_${userId}`.
     - On network error or failure, catches and reads from `AsyncStorage` fallback, returning cached list (or empty array).
   - `addCustomCategory(userId: string, dto: { name: string; icon: string }): Promise<CategoryItem>`:
     - Generates slug-based ID: `custom_${dto.name.trim().toLowerCase().replace(/\s+/g, '-')}_${Date.now()}`.
     - Writes document to `users/${userId}/categories/${id}` with `name`, `icon`, `createdAt: serverTimestamp()`, `updatedAt: serverTimestamp()`.
     - Returns created `CategoryItem`.
   - `deleteCustomCategory(userId: string, categoryId: string): Promise<void>`:
     - Deletes document from `users/${userId}/categories/${categoryId}`.
     - Updates local `AsyncStorage` cache to remove deleted item.

2. Create `__tests__/features/categories/category.service.test.ts`:
   - Mock `firebase/firestore` and `@react-native-async-storage/async-storage`.

   - Test `fetchCustomCategories` returns mapped custom categories from Firestore and stores in AsyncStorage.
   - Test `fetchCustomCategories` falls back to AsyncStorage when Firestore throws an error.
   - Test `addCustomCategory` creates doc in Firestore with slug ID and returns CategoryItem.
   - Test `deleteCustomCategory` calls `deleteDoc` and cleans cache.

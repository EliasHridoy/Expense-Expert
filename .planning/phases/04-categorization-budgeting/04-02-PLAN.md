1. Create `src/features/expenses/utils/filter.util.ts`:
   - Define types:
     ```typescript
     export type DateRangePreset = 'all' | 'today' | 'week' | 'month' | 'custom';
     export type SortOption = 'date_desc' | 'date_asc' | 'amount_desc' | 'amount_asc' | 'title_asc';
     export type GroupOption = 'none' | 'category' | 'date';
     export interface FilterCriteria {
       category: string; // 'all' or category value/id
       dateRange: DateRangePreset;
       customStartDate?: string | null; // ISO string or YYYY-MM-DD
       customEndDate?: string | null;   // ISO string or YYYY-MM-DD
       searchQuery: string;
       sortBy: SortOption;
       groupBy: GroupOption;
     }
     ```
   - Implement `filterExpenses(expenses: Expense[], criteria: FilterCriteria): Expense[]`:
     - Category filter: if `criteria.category !== 'all'`, filters `e.category === criteria.category`.
     - Date range filter:
       - 'today': `isToday(parseISO(e.date))`
       - 'week': `isThisWeek(parseISO(e.date), { weekStartsOn: 1 })` (Monday start)
       - 'month': `isThisMonth(parseISO(e.date))`
       - 'custom': `isWithinInterval(parseISO(e.date), { start: startOfDay(parseISO(customStartDate)), end: endOfDay(parseISO(customEndDate)) })`
       - 'all': returns all
     - Text search filter: case-insensitive check on `e.title.toLowerCase().includes(q)` and optional `e.description?.toLowerCase().includes(q)`.
     - Sorting: calls `sortExpenses(result, criteria.sortBy)`.
   - Implement `sortExpenses(expenses: Expense[], sortBy: SortOption): Expense[]`:
     - 'date_desc': newest first (`getTime(b.date) - getTime(a.date)`)
     - 'date_asc': oldest first (`getTime(a.date) - getTime(b.date)`)
     - 'amount_desc': largest first (`b.amountInCents - a.amountInCents`)
     - 'amount_asc': smallest first (`a.amountInCents - b.amountInCents`)
     - 'title_asc': alphabetical (`a.title.localeCompare(b.title)`)

   - Test sorting options for date desc/asc, amount desc/asc, and alphabetical titles.
   - Test graceful handling of invalid date strings, null descriptions, and empty arrays.
